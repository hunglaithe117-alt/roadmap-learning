# T2.2 — Nét chữ Hán + tone bingo (2026-09-23)

## Stroke order (dữ liệu + check cơ bản)
- **Data**: `strokeSeed` trong `api/chinese_hsk.go` — 12 chữ HSK1 đơn thể
  (人 大 小 中 日 月 水 女 子 好 生 天), thứ tự nét theo bút thuận chuẩn
  phổ thông (教育部《通用规范汉字笔顺规范》); mã nét rút gọn sư phạm
  (h/s/p/n/d/hz/sg/pd — xem comment đầu file, không phải CDL đầy đủ).
- **Endpoint**: `GET /api/zh/strokes?level=HSK1` → index nhẹ
  `[{hanzi, stroke_count}]` cho route **lazy-load**; thêm `&hanzi=X` →
  detail từng nét. Chữ chưa có → 404 (không 500).
- **Canvas** (`web/src/routes/ZhStroke.tsx`): Pointer Events (chuột + touch,
  `touchAction: 'none'`), mỗi nét vẽ → `classifyStroke` theo hướng chủ đạo
  (ngang→h, sổ→s, xuống-trái→p, xuống-phải→n, chấm→d) → `gradeStrokes`
  so thứ tự với chuẩn, pass khi khớp ≥80% và đủ số nét. Đúng → tìm card
  theo mặt chữ (`findCardForHanzi`) → `POST /api/review` grade 4.

## Tone bingo 1 vòng
- **Logic thuần** (`web/src/chinese/bingo.ts`): `dealBoard` (8 chữ + ô free
  giữa, <8 chữ thì throw), `markCell`, `checkWin` (hàng/cột/chéo toàn đúng,
  ô free tính đúng), `boardScore`, `buildBingoResults`.
- **Route** (`web/src/routes/ZhBingo.tsx`): bấm ô → nghe `/api/tts` → gõ tone
  → chấm qua **drill API dùng chung T2.1** (`POST /api/zh/drill/grade`) →
  Bingo → lưu điểm vòng qua `POST /api/zh/bingo/score`.
- **Endpoint** `POST /api/zh/bingo/score {deck_id, results:[{card_id, correct}]}`:
  đúng→grade 4 / sai→grade 1, persist bằng `ScheduleNext` + **1 transaction**
  cho cả vòng (UPDATE cards + INSERT reviews, giữ invariant contract v2);
  card ngoài deck → 400.
