# T9.2 — UI Đồng bộ + xem log xung đột (memory)

## Flow E2E
Cài đặt → "Đồng bộ peer (merge giữ cả hai)" → chọn file backup (.db) máy kia
→ `POST /api/sync` → hiện merged counts (decks/cards/reviews/notes) +
warnings clock-skew (cam) + conflicts của lần merge → log tổng + last_sync_at
tự refresh. Log xung đột read-only, không nút resolve tay (đúng duyệt user).

## Copy an toàn (tránh bấm nhầm)
- Restore: "GHI ĐÈ hủy diệt — ghi đè toàn bộ dữ liệu máy này".
- Sync: "merge giữ cả hai — KHÔNG ghi đè".
- Cờ sync thử nghiệm cũ giữ nguyên (localStorage), chữ cập nhật: merge luôn
  sẵn sàng, status trả last_sync_at.

## API client (web/src/player/api.ts)
- `uploadSync(file)` → SyncResult; `fetchSyncConflicts()` → {conflicts,count};
  `SyncStatus` thêm `last_sync_at?`, `conflicts?` (tương thích mock cũ).
- `ConflictTable` (CaiDat.tsx): cột table/guid(8 ký tự, title đầy đủ)/winner/
  detail/at; dùng chung cho kết quả merge + log tổng.
