# T3.1 — Stress engine (2026-09-23)

Status: completed.

## Thiết kế (dict-first, rule chỉ đoán + gắn nhãn)
- `api/english.go`: `LookupStress(db, word)` → tra `en_dict` exact
  (COLLATE NOCASE) trước; trúng → `source=dict`, `ipa=reading`,
  `stress=StressFromIPA(term, ipa)` (âm tiết sau ˈ viết CAPS, nối `-`).
- Trượt dict → `LookupStressRule` (hậu tố -tion/-sion/-ic/-ity/-ogy/-graphy
  nhấn áp chót, mặc định âm đầu) luôn kèm `exception=true` +
  note "cần kiểm tra dict" — UI `StressCard` hiện nhãn **ngoại lệ** màu cam.
- 14 heteronym danh–động (present/record/content/desert/object/permit/produce/
  refuse/subject/contrast/increase/progress/import/export) có trong cả
  `exceptionWords` + `en_dict` (gloss ghi cả 2 cách đọc) → `source=dict`
  nhưng vẫn `exception=true` với note "danh từ … động từ …".
- Chunking `SplitChunks` (Go + mirror TS `english/chunk.ts`): rule đơn giản
  function-vs-content (~70 từ function: mạo từ/giới từ/đại từ/trợ động từ/
  liên từ); không phân giải ngữ cảnh — đã ghi rõ trong comment + UI.
  `ChunkRow` in content đậm, function mờ.
