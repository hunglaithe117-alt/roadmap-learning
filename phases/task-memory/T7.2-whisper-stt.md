# T7.2 — Whisper STT thật (task memory)

- Trạng thái: **transcript thật** (`engine: faster-whisper`), fallback stub
  khi `WHISPER_URL` trống.
- Service `stt`: image `onerahmet/openai-whisper-asr-webservice:latest`,
  `ASR_MODEL=small`, cùng profile main (luôn bật với `compose up`),
  volume `stt-cache:/root/.cache` persist model giữa restart.
- Adapter Go: POST multipart field `audio_file` → `/asr` với query
  `language=<zh|en từ drill, trống = auto-detect>` + `vad_filter=true` +
  `beam_size=1` + `output=json` (service mặc định trả text/plain nên bắt
  buộc xin json); join `segments[].text`, map `language`/`words` vào
  contract `{transcript, lang, words?, confidence?}`.
- Quyết định chốt: **model small** (user duyệt).

## Transcript + latency thật (2026-09-23, máy build, CPU)

| Câu mẫu (~5s, wav 22kHz do Piper TTS tạo) | Transcript | Latency e2e qua `POST /api/stt?lang=` |
|---|---|---|
| zh 你好，很高兴认识你。我正在学习中文，希望每天进步一点点。 (4,84s) | 你好很高興認識你我正在學習中文希望每天經不一點點 (đúng ~90%, ra phồn thể + sai 2 chữ cuối) | **~1,57s** (trực tiếp /asr ~1,8s) |
| en Hello, nice to meet you. I am learning English and I practice every single day. (4,5s) | khớp 100% | **~1,61s** (trực tiếp /asr ~1,49s) |

## Dung lượng / RAM (đo thật)

- Image sidecar: **8,19GB** (`onerahmet/...:latest` — gồm torch + pyannote
  + deps, nặng hơn ước tính ban đầu ~2GB; đã ghi rõ để cân nhắc image nhẹ
  hơn về sau, ngoài scope T7.2).
- Model `small` tải runtime: `small.pt` **462MB** tại `/root/.cache/whisper/`
  (persist trong volume `stt-cache`).
- RAM container `stt` khi model đã load (idle): **~1,61 GiB** (đúng estimate ~1,5GB).
- Máy yếu: đổi `ASR_MODEL: base` trong compose (chưa đo, transcript sẽ kém hơn).
