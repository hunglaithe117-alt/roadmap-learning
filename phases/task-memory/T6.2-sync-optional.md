# T6.2 — Sync optional đa thiết bị (done, scope hẹp đúng plan)

## Làm gì
- `GET /api/backup` → file SQLite snapshot nhất quán (`VACUUM INTO`, kèm
  Content-Disposition attachment). Test roundtrip: backup → xóa deck →
  restore → decks + reviews về đủ.
- `POST /api/restore` (multipart field `backup`/`file`, ≤64MB): validate magic
  `SQLite format 3` + đủ table core, rồi ATTACH + chép từng table trong 1
  transaction (xóa con-trước, chèn cha-trước để FK thỏa). File rác → 400.
  Không thay file DB đang mở → không restart, không thêm cột/table.
- Sync thật (Turso/PowerSync/merge last-write-win) KHÔNG làm — là TƯƠNG LAI v2:
  `GET /api/sync/status` → `{enabled:false, strategy:"last-write-win"}`,
  `POST /api/sync` → 403 khi tắt (mặc định), 501 khi bật cờ thử nghiệm.
  Cờ `SYNC_ENABLED` (server, mặc định tắt) + cờ UI `syncEnabled` ở route Cài đặt.
- Route Cài đặt: thêm section Backup/Restore (link tải + input file upload) và
  toggle sync (mặc định tắt, bật thì hiện chú thích "chỉ cờ UI, dùng backup").
