# T0.2 — Báo cáo spike audio sidecar (2026-09-23)

## TTS/STT: thật hay stub?
**STUB — cả hai.** Không tải model thật, dừng đúng ngưỡng task cho phép:
- Probe máy: `piper`/`piper-tts` không có trên PATH, không có voice `*.onnx` nào
  (`~/.local/share/piper`, `/usr/share/piper` đều trống); `whisper`/`faster-whisper` không có.
- faster-whisper sidecar thật kéo Python + torch/CUDA, vượt ngưỡng **1GB** task đặt ra
  → **DỪNG, không tải tiếp.** Piper voice (~60MB) + binary về lý thuyết vừa ngưỡng,
  nhưng không có mạng đảm bảo + cần build sidecar Python; spike ưu tiên chứng minh
  interface + browser flow trước, model thật để phase-1 khi chốt infra.
- Code đã sẵn sàng đổi stub → thật **chỉ bằng biến môi trường, không sửa code**:
  - `PIPER_BIN` (mặc định `piper` trên PATH) + `PIPER_MODEL` (đường dẫn voice `.onnx`)
    → `NewTTSEngineFromEnv()` dùng `PiperTTSEngine` (os/exec, stdin=text, đọc wav file ra).
  - `WHISPER_URL` (vd `http://localhost:9000/transcribe`) → `NewSTTEngineFromEnv()`
    dùng `FasterWhisperEngine` (POST multipart field `audio`, đọc JSON `{transcript, lang}`).

## Skeleton đã dựng
- `api/audio.go`: interface `TTSEngine`/`STTEngine`, `StubTTSEngine` (sinh WAV sine
  PCM16 mono 16kHz 0.5s, 16044 bytes — `<audio>` play được offline),
  `PiperTTSEngine`, `FasterWhisperEngine`, `TTSHandler` (`GET /api/tts?text=`, tối đa
  500 chars, timeout 30s), `STTHandler` (`POST /api/stt` multipart field `audio`,
  tối đa 10MB, timeout 60s). Lỗi sidecar/timeout trả JSON rõ cho UI:
  400 thiếu/sai input, 502 sidecar fail (`stt failed…`/`tts failed…`),
  504 timeout (`tts timeout`/`stt timeout`), header `X-Engine: stub|piper|faster-whisper`.
- `api/main.go`: `NewMux` đăng ký thêm `/api/tts`, `/api/stt` (giữ nguyên chữ ký, test cũ không vỡ).
- `web/src/api.ts`: thêm `buildTTSUrl(text)`, `uploadSTT(blob)→{transcript, lang, engine}`.
- `web/src/App.tsx`: thêm section “Audio Spike T0.2” — input text + nút Play TTS
  (`<audio controls src=/api/tts?text=…>`), nút Record/Stop & transcribe
  (MediaRecorder → uploadSTT → hiện transcript), báo lỗi khi browser thiếu MediaRecorder.
- `api/audio_test.go` (7 test), `web/src/audio.test.ts` (3 test).

## Chốt kiến trúc
- **Sidecar RỜI qua HTTP** (Go API chỉ proxy, không nhúng model): `WHISPER_URL` trỏ sang
  process/container faster-whisper riêng. Lý do: image Python/torch nặng, tách để Go API
  nhẹ + scale/restart độc lập; timeout 60s + 502/504 đã có; hợp đồng HTTP đã chứng minh
  bằng test roundtrip (`Test_stt_sidecar_http_returns_transcript`). Chung host chỉ nên
  dùng ở dev (chạy 2 process cùng máy), giữ nguyên boundary HTTP để tách sau miễn phí.
- **Piper cho phase-1, Kokoro để ngỏ**: Piper CLI + voice onnx offline (~tens MB),
  gọi qua os/exec đơn giản, đủ cho tone-pair/shadowing; Kokoro giọng tự nhiên hơn nhưng
  nặng và phức tạp deploy — chỉ xem lại nếu user chê giọng Piper ở human review.
