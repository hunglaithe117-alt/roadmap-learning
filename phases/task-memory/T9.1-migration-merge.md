# T9.1 — Migration v3 + merge file-carry (memory)

## Luật merge (1 tx ATTACH incoming, POST /api/sync field backup/file)
- decks/cards LWW theo `updated_at`, so khớp theo `guid` (KHÔNG tin id số).
  Tombstone `deleted=1` thắng khi newer; hòa ts + một bên deleted → deleted thắng.
- Conflict log khi cả 2 phía `> last_sync_at` và khác nhau (winner = bên newer).
- reviews: append `INSERT OR IGNORE` theo guid (fallback legacy
  card+reviewed_at+grade) → recompute `reps=COUNT` + replay `ScheduleNext`
  theo `reviewed_at` → log `reps-recomputed`.
- notes: union theo guid (legacy fallback card+text+created_at); card không
  resolve được → NULL để giữ nội dung.
- Bỏ qua dict/en_dict/seed; remap deck/card guid→id local.
- Legacy (snapshot thiếu cột v3): match natural key (deck theo name, card theo
  deck+front); ts fallback created_at; hòa ts + khác nội dung → incoming thắng
  + log `legacy-tie-incoming-wins` (file-carry đi xuôi thời gian).
- Clock-skew: `|now - incoming.max(updated_at)| > 24h` hoặc future → warnings.
- Xong: `last_sync_at=now`; trả `{merged, conflicts[], warnings[]}`.
- `POST /api/restore` giữ nguyên hủy diệt (chép giao cột + gồm sync_meta/
  sync_conflicts); stub 403/501 Phase 6 đã xóa, status luôn enabled.

## Migration v3 (idempotent, OpenDB chạy + ghi version 3)
- decks/cards: `guid TEXT` + `updated_at TEXT NOT NULL DEFAULT ''` +
  `deleted INTEGER NOT NULL DEFAULT 0`; reviews/notes: `guid TEXT`.
- Backfill: guid=uuid4 từng row; updated_at=COALESCE(created_at, now).
- UNIQUE INDEX guid ×4; `sync_meta(k,v)` + `sync_conflicts`; trigger AFTER
  UPDATE chạm updated_at khi `NEW IS OLD` VÀ `OLD != now-second` (chặn đệ quy
  vô hạn khi 2 UPDATE cùng 1 giây — strftime chỉ chính xác tới giây).
- Mọi INSERT mới (deck/card/review/note, seed demo, HSK, EN, ERR/SHADOW/THIEU)
  gán guid; UPDATE thường chạm updated_at qua trigger; merge set tường minh.
- DELETE deck/card → xóa mềm tombstone (lan xuống cards); mọi API đọc lọc
  `deleted=0` (list/get/due/review/suggest/stats/drill/bingo/tone).

## Robustness seed HSK (chọn: cấm deck custom)
- `POST /api/zh/import`: deck phải == level (400 nếu custom) — key
  (deck_id, front) không lẫn chéo level khi merge; 1 tx + INSERT OR IGNORE,
  COUNT qua RowsAffected; dict giữ key hanzi (FTS lookup).
- hanzi trùng chéo level: grep toàn bộ seed HSK1 (36) + HSK2 (147) + HSK3
  (298) + HSK4 (598) = 1079 rows / 1079 hanzi unique → 0 trùng → dict
  hanzi-only an toàn.
