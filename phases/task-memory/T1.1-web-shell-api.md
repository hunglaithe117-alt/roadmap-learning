# T1.1 — Web shell + Go API + SQLite (2026-09-23)

## Remediation cổng D1 (làm trước, oracle đã duyệt)
5 sửa trong `api/audio.go` + handlers:
1. `FasterWhisperEngine.Transcribe` stream multipart qua `io.Pipe` + goroutine
   (writer → pipe → HTTP request), không buffer 2 lần trong `bytes.Buffer`.
   Lỗi writer propagate qua channel buffered; `pr.Close()` khi `client.Do` fail
   để không leak goroutine.
2. Lỗi engine chi tiết chỉ `log.Printf` server-side; client nhận message gọn
   (`"tts failed"` / `"stt failed"` / `"… timeout"` / `"… cancelled"`) + header `X-Engine`.
   Test assert detail (`"sidecar down"`) KHÔNG leak ra client.
3. `context.Canceled` → **499** (`"tts cancelled"`), chỉ `DeadlineExceeded` → **504**.
   Helper `engineHTTPStatus(ctx, err)` check `errors.Is` trước rồi mới `ctx.Err()`.
4. `X-Engine` set ngay đầu handler → có mặt cả khi trả lỗi (cả validation 4xx).
5. STT JSON: struct `STTResponse{transcript, lang, engine, words?, confidence?}`
   + `STTWord{word, start?, end?, confidence?}` — optional `omitempty`/nullable,
   `json.Unmarshal` payload cũ (vắng fields) vẫn qua. Sidecar có trả
   `words/confidence` thì parse passthrough.
- Phụ: `ttsTimeout/sttTimeout` đổi từ `const` sang `var` để test deadline được;
  test timeout cũ (cancel → 504) sửa thành cancel → 499 + thêm test deadline → 504.

## Schema (SQLite file, versioned từ đầu)
File `api/schema.sql` (`//go:embed`), version ghi `schema_migrations` (=1):
- `decks(id, name, lang, created_at)`
- `cards(id, deck_id FK CASCADE, front, back, pinyin, due_at UTC RFC3339,
  stability, difficulty, reps, lapses, state, created_at)` + index `(deck_id, due_at)`
- `reviews(id, card_id FK CASCADE, grade, reviewed_at, next_due_at)` + index `(card_id)`
- `notes(id, card_id FK CASCADE NULL, text, created_at)`
- `dict` FTS5 `(hanzi, pinyin, nghia)` (giữ từ phase-0)
- DB file: `OpenDB(dsn)` / `DefaultDSN()` = `$LANGAPP_DB` hoặc `./langapp.db`
  (thay `:memory:`); test dùng `OpenDB(":memory:")` hoặc temp file.
  `PRAGMA busy_timeout=5000`, `SetMaxOpenConns(1)`.

## CRUD API (message lỗi tiếng Việt, shape `{"error": msg}` giữ nguyên)
- `GET/POST /api/decks`, `GET/DELETE /api/decks/{id}`
- `GET/POST /api/decks/{id}/cards`, `GET/PATCH/DELETE /api/cards/{id}`
- `GET/POST /api/cards/{id}/notes`, `DELETE /api/notes/{id}`
- `GET /api/search`, `/api/health`, `/api/tts`, `/api/stt` giữ nguyên
- Card mới: `due_at = now+24h` (UTC), `state='new'`.
- Seed idempotent `SeedDemo`: deck HSK1 (zh) + PVO (en), mỗi deck 10 cards,
  guard theo `name`/`(deck_id, front)` → chạy 2 lần vẫn 2 decks / 20 cards.
  `main()` gọi `SeedDemo` khi boot.

## Web shell (hash router, KHÔNG thêm dep)
- `src/router.ts`: `matchRoute(hash)` pure + `ROUTES` —
  không dùng react-router (tránh dep mới, vitest không cần jsdom).
- `App.tsx` = AppShell: nav Học/Review/Cài đặt + `hashchange` listener + outlet.
  Direct URL `#/review` load được (hash, không 404 server).
- `routes/Hoc.tsx`: list decks từ `GET /api/decks` + form tạo deck + tra từ điển FTS5.
- `routes/Review.tsx`: chọn deck → queue due cards → ReviewCard + chấm 1-4.
- `routes/CaiDat.tsx`: config API base (localStorage) + health + audio demo T0.2 dời sang.
- `api.ts`: thêm types `Deck/Card/Note/ReviewResult`, `getApiBase()`,
  `fetchDecks/createDeck/fetchCards/createCard/fetchDueCards/postReview/fetchNotes/createNote`;
  lỗi server parse `body.error` (tiếng Việt) rồi throw.
