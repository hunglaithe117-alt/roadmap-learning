# T7.1 — Piper TTS thật (task memory)

- Trạng thái: **giọng thật** (`X-Engine: piper`), fallback stub khi thiếu binary/voice.
- Engine: OHF-Voice/piper1-gpl v1.6.1 (wheel manylinux x86_64 + onnxruntime/numpy).
- Voice: `zh_CN-huayan-medium` (63.201.294 bytes ≈ 60,3 MiB + json 4,8KB),
  `en_US-lessac-medium` (63.201.294 bytes ≈ 60,3 MiB + json 4,9KB),
  nguồn rhasspy/piper-voices (HuggingFace `resolve/main/...`).
- Chọn voice theo lang: `PIPER_MODEL_ZH` / `PIPER_MODEL_EN` (fallback
  `PIPER_MODEL` chung); `PIPER_BIN` trỏ binary (mặc định `piper` trên PATH,
  trong image là `/usr/local/bin/piper`). Không hardcode path trong code.
- Cache server-side theo (text, lang, voice model path) — sha1, cap 200
  entries, đổi voice là miss. `Cache-Control: no-store` giữ nguyên (client
  không cache, server cache).

## Latency thật (2026-09-23, máy build, CPU, đo qua `GET /api/tts`)

| Câu mẫu | Audio ra | Cold (exec piper) | Cache hit |
|---|---|---|---|
| zh 你好，很高兴认识你 (~2s) | 1,88s wav 22kHz mono | **~0,94s** | **~0,3ms** |
| en Hello, nice to meet you (~1,4s) | 1,40s wav 22kHz mono | **~0,90s** | ~0,3ms |

- RAM infer Piper <300MB (exec ngắn hạn, không resident).
- Disk thêm vào image: engine + deps pip ~100MB, 2 voice ~127MB.
- Image `lang-learn-app:phase7` build thật: **752MB** (đo 2026-09-23;
  runtime python:3.11-slim + piper + voices + Go binary + web dist).
  Smoke trong container: `X-Engine: piper` cả zh/en, wav hợp lệ.
