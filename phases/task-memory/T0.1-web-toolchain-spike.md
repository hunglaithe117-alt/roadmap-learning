## Lưu ý môi trường
- Cổng 8080 trên máy đang bị chiếm bởi tiến trình khác (trả 404 + header CSP lạ), nên spike chạy API ở `PORT=18080`. Sang phase-1 nên thống nhất cổng (ví dụ giữ 8080 nếu máy dev sạch, hoặc pin 18080) và ghi vào config.
- Build lần đầu `modernc.org/sqlite` mất vài phút tải module (cache xong các lần sau nhanh). Không cần cgo — phù hợp offline.
- Browser thật chưa test tay (không có GUI trong môi trường này); thay bằng vitest mock fetch + curl vào server thật. Vite dev proxy đã cấu hình, phase-1 nên chạy `pnpm dev` + `PORT=... go run ./api` song song để kiểm tra SPA fetch end-to-end trên Chrome/Firefox.
