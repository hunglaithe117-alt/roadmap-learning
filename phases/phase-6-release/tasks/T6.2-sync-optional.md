# T6.2 — Sync optional đa thiết bị (tắt mặc định)
## Why
Sync giúp học tiếp giữa máy bàn + laptop nhưng dễ phình scope v1.
Giữ optional, single-user offline là mặc định an toàn.
## Pre-conditions
- T6.1 xong (deploy Docker ổn định).
- User trả lời có cần auth/sync ở v1 không.
## What to do
### Step 1 — Export/import snapshot SQLite
```python
# pseudo: snapshot
snap = export("/api/backup", format="sqlite-dump")
restore("/api/restore", file=snap)
check("decks + streak identical after restore")
```
### Step 2 — Sync endpoint last-write-win + log xung đột
```python
# pseudo: sync merge
merged = merge(local, remote, rule="last-write-win")
write_log("sync.log", conflicts=merged.conflicts)
check("no silent data loss on conflict")
```
### Step 3 — Cờ bật/tắt sync + cắt scope nếu thiếu giờ
```python
# pseudo: feature flag
flag("SYNC_ENABLED", default=False)
check("sync off keeps full offline flow")
```
## Code style reminder
Test đặt tên `test_<unit>_<scenario>_<expected>`; không dùng comment Arrange/Act/Assert.
