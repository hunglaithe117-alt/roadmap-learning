# T6.1 — Docker + deploy 1 lệnh (web + api + sidecar)
## Why
Web không cần packaging Wails/Tauri; Docker là cách phân phối duy nhất của v1.
Cần `compose up` là chạy full stack kể cả STT/TTS nặng.
## Pre-conditions
- Mọi phase 0-5 xong; frontend build static được.
- Biết dung lượng model whisper + voice để tách image.
## What to do
### Step 1 — Dockerfile backend + frontend static
```python
# pseudo: images
build("api: go build -o server ./api")  # single binary
build("web: pnpm build -> dist served by api/static")
check("GET /api/health == 200 inside container")
```
### Step 2 — Compose full stack + volume persist
```python
# pseudo: compose stack
services = ["web+api", "stt-sidecar", "tts-sidecar"]
up("docker compose up -d", volumes=["sqlite-data", "models"])
check("restart keeps decks and streak")
```
### Step 3 — Smoke test sau deploy + ghi README deploy
```python
# pseudo: deploy smoke
run("curl /api/health, /api/search?q=ni, /api/stats?range=week")
write("DEPLOY.md", steps=["compose up", "backup volume"])
```
## Code style reminder
Test đặt tên `test_<unit>_<scenario>_<expected>`; không dùng comment Arrange/Act/Assert.
## Post-conditions
- `docker compose up` chạy full stack, data persist qua restart.
- DEPLOY.md ghi đủ bước deploy + backup volume.
