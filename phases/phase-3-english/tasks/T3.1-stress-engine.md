# T3.1 — Stress engine (trọng âm + chunking trên web)
## Why
Trọng âm + chunking là nền NGONG S01-S24; user mới hay đọc đều đều sai nhịp.
Engine này nuôi drill PVO/TMRND và checklist THIEU sau đó.
## Pre-conditions
- Phase 1 xong (deck/SRS/FTS5 API sẵn).
- Có nguồn dict stress + ví dụ NGONG S01-S24.
## What to do
### Step 1 — Hiển thị trọng âm + audio mẫu từng từ
```python
# pseudo: stress display
entry = lookup("photograph", field="stress")  # PHO-to-graph
audio = get("/api/tts?text=photograph")
render("StressCard(word, marks=entry.marks, audio_button)")
```
### Step 2 — Tự tách chunk cho câu mẫu
```python
# pseudo: chunking
chunks = split_chunks("I want to make progress", rule="function-vs-content")
render("ChunkRow(chunks, tap_highlight=True)")
check("content words bold, function words dim")
```
### Step 3 — Drill stress theo ngày lưu SRS
```python
# pseudo: stress drill review
card = next_due(deck="NGONG-S01")
grade = ask_user(card.audio, card.marks)
post("/api/review", {"card_id": card.id, "grade": grade})
```
