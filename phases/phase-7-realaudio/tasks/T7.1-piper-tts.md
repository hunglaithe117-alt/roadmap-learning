# T7.1 — Piper TTS thật (os/exec trực tiếp, X-Engine: piper)
## Why
`/api/tts` v1 còn stub/giọng giả; cần giọng thật Trung + Anh offline, nhẹ CPU,
không thêm sidecar HTTP. Piper chạy `os/exec` trực tiếp là đường đơn giản nhất
(engine ~32MB + 2 voice ~63MB/voice).
## Pre-conditions
- API Go v1 chạy được, endpoint `/api/tts` stub còn giữ.
- Env `PIPER_BIN` / `PIPER_MODEL` đã có sẵn trong code (đọc env, không hardcode path).
- Đã tải engine OHF-Voice/piper1-gpl v1.6.1 + voice `zh_CN-huayan-medium` +
  `en_US-lessac-medium`.
## What to do
### Step 1 — Chạy Piper bằng os/exec, chọn voice theo lang
```python
# pseudo: api/tts.go — SynthesizeViaPiper(text, lang)
wav = exec(PIPER_BIN, ["-m", model_for(lang), "--output-raw"])  # stdin=text
check(header(wav) == "RIFF" and duration(wav) > 0)
```
### Step 2 — Gắn header X-Engine + cache theo (text, lang, voice)
```python
# pseudo: api/tts.go — HandleTTS(w, r)
key = cache_key(text, lang, voice_version)  # sha1
serve_or_synthesize(key, lambda: SynthesizeViaPiper(text, lang))
set_header(w, "X-Engine", "piper")
```
### Step 3 — Smoke giọng thật zh + en + ghi latency
```python
# pseudo: scripts/smoke_tts.sh
curl("/api/tts?text=ni3hao3&lang=zh") -> check("X-Engine == piper")
curl("/api/tts?text=hello&lang=en") -> check("X-Engine == piper")
record("phases/task-memory/T7.1-piper-tts.md", latency_zh_ms, latency_en_ms)
```
