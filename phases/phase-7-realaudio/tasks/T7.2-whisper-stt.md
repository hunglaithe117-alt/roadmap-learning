# T7.2 — Whisper STT thật (faster-whisper service, join segments)
## Why
`/api/stt` v1 chưa transcript thật; cần service STT CPU offline cho câu mẫu
Trung + Anh, latency câu ngắn 1-3s, Go chỉ viết adapter mỏng.
## Pre-conditions
- Image `onerahmet/openai-whisper-asr-webservice` kéo được (faster-whisper,
  model small CPU int8 ~466MB disk / ~1.5GB RAM).
- Service `stt` trong compose (port 9000, volume `stt-cache`) chạy được.
- Có 2 file câu mẫu: 1 Trung + 1 Anh (wav 16kHz).
## What to do
### Step 1 — Dựng service stt trong compose (small, int8, VAD)
```python
# pseudo: docker-compose.yml — service stt
up("stt: image=openai-whisper-asr-webservice, port=9000, volume=stt-cache")
check("POST stt:9000/asr?language=zh&vad_filter=true&beam_size=1 == 200")
```
### Step 2 — Viết adapter Go join segments[].text
```python
# pseudo: api/stt.go — TranscribeViaService(audio, lang)
resp = post("http://stt:9000/asr", multipart(audio), params={"language": lang, "vad_filter": True, "beam_size": 1})
text = join_segments(resp["segments"], key="text")  # ~10 dòng
return {"text": text.strip(), "lang": lang}
```
### Step 3 — Smoke transcript thật zh + en + ghi latency
```python
# pseudo: scripts/smoke_stt.sh
curl_post("/api/stt", file=sample_zh_wav, lang="zh") -> check("transcript non-empty")
curl_post("/api/stt", file=sample_en_wav, lang="en") -> check("transcript non-empty")
record("phases/task-memory/T7.2-whisper-stt.md", latency_zh_ms, latency_en_ms)
```
