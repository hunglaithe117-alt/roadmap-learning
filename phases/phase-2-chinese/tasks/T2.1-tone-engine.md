# T2.1 — Tone engine (pinyin + tone-pair drill trên web)
## Why
Thanh điệu là rào cản lớn nhất người mới học Trung; drill tone-pair daily 10p giữ thói quen.
Engine này nuôi cả bingo (T2.2) và shadowing (phase-4).
## Pre-conditions
- Phase 1 xong (deck/SRS/FTS5 API sẵn).
- pinyin-pro đã thêm vào web dependencies.
## What to do
### Step 1 — Hiển thị pinyin có dấu + audio mẫu từng tone
```python
# pseudo: pinyin display
py = pinyin_pro("你好", tone="marks")  # -> nǐ hǎo
audio = get("/api/tts?text=你好")
render("ToneCard(hanzi, py, audio_button)")
```
### Step 2 — Drill tone-pair chấm điểm qua API
```python
# pseudo: tone-pair drill
pair = pick_pair(["1-4", "2-3", "3-4"])
grade = compare(user_tone_input, pair.expected)
post("/api/review", {"card_id": pair.id, "grade": grade})
```
### Step 3 — Import deck HSK1-HSK2 mẫu qua endpoint
```python
# pseudo: import hsk decks
import_csv("hsk1-150.csv", deck="HSK1")
assert fts("GET /api/search?q=ni") contains "你"
```
