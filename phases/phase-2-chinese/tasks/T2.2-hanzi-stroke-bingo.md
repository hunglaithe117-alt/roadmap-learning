# T2.2 — Nét chữ Hán + game tone bingo trên web
## Why
Viết đúng thứ tự nét giúp nhớ chữ lâu; bingo biến drill tone khô thành game daily.
Cả hai giữ động lực cho G1-G4 HSK 150→1200 từ.
## Pre-conditions
- T2.1 xong (tone engine + deck HSK API).
- Có dữ liệu thứ tự nét (lazy-load theo level).
## What to do
### Step 1 — Canvas viết chữ check thứ tự nét
```python
# pseudo: stroke order check
strokes = load_strokes("好", level="HSK1")
result = check_order(user_strokes, strokes.expected)
render("StrokeCanvas(progress=result.pct)")
```
### Step 2 — Game tone bingo 1 vòng lưu điểm SRS
```python
# pseudo: bingo round
board = deal_board(pairs=8, deck="HSK1")
score = play_round(board, user_answers)
post("/api/review", {"deck": "HSK1", "score": score})
```
### Step 3 — Lazy-load dữ liệu nét theo HSK level
```python
# pseudo: lazy stroke data
route("/hoc/trung/viet?level=HSK2", loader=fetch_strokes_lazy)
assert first_paint_ms() < 800
```
