# T4.2 — Recorder so sánh + ErrorBook trên web
## Why
Ghi âm + self-correction là daily Anh; so STT với mẫu giúp user tự sửa.
ErrorBook gom lỗi lặp để SRS nhắc lại đúng chỗ yếu.
## Pre-conditions
- T4.1 xong (player + audio pipeline).
- STT API từ T0.2 hoạt động với webm/opus.
## What to do
### Step 1 — Ghi âm MediaRecorder upload về STT API
```python
# pseudo: record and transcribe
blob = record_media(mime="audio/webm", max_sec=60)
resp = post("/api/stt", files={"audio": blob})
check("resp.transcript is non_empty")
```
### Step 2 — Diff transcript với câu mẫu highlight từ sai
```python
# pseudo: diff highlight
diff = word_diff(expected="ni hao ma", got=resp.transcript)
render("DiffView(diff, wrong=red, missing=amber)")
check("wrong words clickable to replay TTS")
```
### Step 3 — ErrorBook tự thêm lỗi + gợi ý ôn SRS
```python
# pseudo: errorbook
post("/api/errors", {"card_id": 1, "wrong": diff.wrong})
suggest = get("/api/review?suggest=errors&limit=10")
check("repeated errors appear in review queue")
```
