# T4.1 — Shadow player A-B loop trên web
## Why
Shadowing daily là thói quen chung Anh (G0 METHODS) + Trung (10-10-10).
Player A-B loop + chỉnh tốc độ là công cụ dùng mỗi ngày.
## Pre-conditions
- Phase 1 xong; nên có engine phase 2/3 để test câu thật.
- Audio mẫu TTS đã stream được từ T0.2.
## What to do
### Step 1 — Player A-B loop chỉnh tốc độ 0.5x-1.5x
```python
# pseudo: ab loop player
player = AudioPlayer(src="/api/tts?text=...", rate=0.8)
player.set_loop(a_sec=1.2, b_sec=3.4)
check("loop repeats segment without gap click")
```
### Step 2 — Playlist theo deck + lưu vị trí học
```python
# pseudo: playlist progress
queue = get("/api/decks/HSK1/cards?due=today")
post("/api/progress", {"card_id": q[0].id, "loops": 5})
check("resume restores last card index")
```
### Step 3 — Phím tắt + responsive mobile
```python
# pseudo: shortcuts
bind({"space": "play/pause", "[": "set A", "]": "set B"})
check("player usable at 360px width")
```
