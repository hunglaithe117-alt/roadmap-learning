# T5.2 — Dashboard weekly/monthly + streak nhắc học
## Why
Review weekly 30p/monthly 90p + streak giữ thói quen dài hạn hai ngôn ngữ.
Dashboard biến dữ liệu SRS/ErrorBook thành hành động ôn cụ thể.
## Pre-conditions
- T5.1 xong; API review/error/THIEU có dữ liệu thật.
- Notification API test được trên Chrome/Firefox.
## What to do
### Step 1 — API stats tuần/tháng + top lỗi lặp
```python
# pseudo: stats endpoint
stats = get("/api/stats?range=week")  # due, done, accuracy
top = get("/api/errors/top?limit=10")
check("stats.done + stats.pending == stats.total")
```
### Step 2 — Dashboard route vẽ tiến độ + lỗi lặp
```python
# pseudo: dashboard view
render("Dashboard(weekly=stats, monthly=stats, topErrors=top)")
check("click error navigates to review card")
```
### Step 3 — Streak + nhắc học bằng Notification API
```python
# pseudo: streak reminder
streak = compute_streak(days_learned)  # consecutive UTC days
notify("Hôm nay chưa ôn SRS", when="20:00", fallback="in-app badge")
```
