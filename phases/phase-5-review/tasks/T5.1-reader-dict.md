# T5.1 — Graded reader + tra từ nhanh trên web
## Why
Đọc hiểu graded reader khóa G3 Trung + G4 Anh; bấm từ tra <200ms giữ mạch đọc.
Tích hợp SRS để biến từ mới thành card ôn.
## Pre-conditions
- Phase 1 + 4 xong (API deck/SRS/errorbook sẵn).
- Có text public domain/tự biên, không dính bản quyền.
## What to do
### Step 1 — Route đọc bài + bấm từ tra FTS5
```python
# pseudo: reader lookup
article = get("/api/reader?level=HSK2&id=1")
entry = get("/api/search?q=" + clicked_word)
check("popup shows pinyin + nghia within 200ms")
```
### Step 2 — Lưu từ mới thành card SRS 1 chạm
```python
# pseudo: save word to srs
post("/api/cards", {"deck": "HSK2", "front": word, "back": entry.nghia})
check("new card due tomorrow per fallback 1-3-7-14-30")
```
### Step 3 — Phân level bài đọc theo HSK/CEFR
```python
# pseudo: reader levels
levels = get("/api/reader/levels")  # HSK1-4, A1-B2
check("filter by level returns only matching articles")
```
