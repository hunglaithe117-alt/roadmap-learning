# T0.2 — Spike audio sidecar qua backend (TTS + STT)
## Why
Audio là lõi shadowing/tone-pair; phải chứng minh browser thu/phát được qua backend.
Quyết định Piper/Kokoro và faster-whisper sidecar rời hay chung host.
## Pre-conditions
- T0.1 xong (SPA gọi được Go API).
- Có sẵn 1 voice model Piper/Kokoro và 1 model whisper nhỏ.
## What to do
### Step 1 — TTS qua backend stream về thẻ audio
```python
# pseudo: tts endpoint streams audio
run("piper --model vi.onnx --text 'ni hao' --out /tmp/t.wav")
add_route("GET /api/tts?text=", handler=exec_tts_stream)
check("browser <audio> plays stream offline")
```
### Step 2 — Ghi âm browser upload về STT sidecar
```python
# pseudo: recorder upload to stt
blob = media_recorder_stop(format="webm/opus")
resp = post("/api/stt", files={"audio": blob})
assert "transcript" in resp and resp.lang in ["zh", "en", "vi"]
```
### Step 3 — Đo latency và chốt kiến trúc sidecar
```python
# pseudo: latency table
table = bench({"tts_piper": ms1, "tts_kokoro": ms2, "stt_whisper": ms3})
decide("sidecar rời vs chung host", rule="stt_p95 < 5s")
```
