# T0.1 — Spike toolchain web (Vite + Go API + SQLite)
## Why
Cần chứng minh SPA gọi được Go API và SQLite FTS5 trước khi chốt stack web-v1.
Tránh kẹt toolchain như rủi ro WebView thời desktop.
## Pre-conditions
- Đã cài Go toolchain, pnpm, browser Chrome/Firefox.
- Chưa cần sidecar TTS/STT ở task này.
## What to do
### Step 1 — Dựng skeleton Vite SPA + Go health API
```python
# pseudo: scaffold web skeleton
run("pnpm create vite web --template react-ts")
run("go mod init langapp && go run ./api --port 8080")
check("GET /api/health == 200 from SPA fetch")
```
### Step 2 — Nối SQLite FTS5 pure-Go qua endpoint search
```python
# pseudo: fts5 search endpoint
db.exec("CREATE VIRTUAL TABLE dict USING fts5(hanzi, pinyin, nghia)")
add_route("GET /api/search?q=", handler=fts_query)
assert latency_ms("ni hao") < 100
```
### Step 3 — Ghi kết quả spike vào báo cáo
```python
# pseudo: record spike result
report = collect(versions=["go", "pnpm", "sqlite-fts5"])
write("phases/task-memory/T0.1-spike.md", report)
```
