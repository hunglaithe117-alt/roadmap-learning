# T8.1 — Import HSK 2.0 L1-L4 (1200 từ, idempotent, nghĩa Việt tự soạn)
## Why
App cần đủ 1200 từ HSK L1-L4 làm lõi học tiếng Trung; nguồn mở MIT sẵn có,
endpoint import đã có — chỉ cần pipeline seed sạch, idempotent, hợp pháp.
## Pre-conditions
- Endpoint import deck/card chạy được, chạy lại không tạo trùng.
- Nguồn chính `drkameleon/complete-hsk-vocabulary` (MIT, JSON) tải được;
  backup `clem109/hsk-vocabulary` (MIT, CSV).
## What to do
### Step 1 — Tải nguồn chính + đối chiếu backup
```python
# pseudo: scripts/fetch_hsk.py — FetchHSK(levels=[1,2,3,4])
raw = download("drkameleon/complete-hsk-vocabulary")  # JSON, MIT
fallback = download("clem109/hsk-vocabulary")  # CSV, MIT backup
check("count(raw, L1-L4) == 1200 and diff(raw, fallback) logged")
```
### Step 2 — Soạn nghĩa Việt + đối chiếu pinyin rồi import idempotent
```python
# pseudo: scripts/seed_hsk.py — SeedHSK(words)
rows = add_vietnamese_gloss(words)  # tự soạn, KHÔNG copy tài liệu bản quyền
rows = crosscheck_pinyin(rows)  # đối chiếu, sửa lệch
post("/api/import", rows, key="hanzi+level")  # idempotent upsert
```
### Step 3 — Verify 1200 từ + FTS search được
```python
# pseudo: scripts/verify_hsk.py
check("count(DB, level<=4) == 1200 and rerun_import == no_dupes")
check("GET /api/search?q=ni == hits and /api/search?q=你 == hits")
```
