# T9.2 — UI Đồng bộ + xem log xung đột (Cài đặt)
## Why
Merge T9.1 chỉ có giá trị khi user tự làm được: backup → chép tay → upload merge
ngay trong Cài đặt, thấy được xung đột nào đã thắng và `last_sync_at`.
## Pre-conditions
- T9.1 xong: `POST /api/sync` merge + `sync_conflicts` + `last_sync_at` chạy được.
- Trang Cài đặt SPA hiện tại (backup/restore hủy diệt) còn nguyên.
## What to do
### Step 1 — Nút Đồng bộ (chọn file backup máy kia → POST /api/sync)
```python
# pseudo: web/src/pages/Settings.tsx — SyncSection()
file = pick_file(input accept=".db,.sqlite")  # file backup chép tay từ máy kia
result = post_multipart("/api/sync", file)  # merged counts + warnings
show("merged decks/cards/reviews/notes + cảnh báo lệch đồng hồ")
```
### Step 2 — Xem log xung đột + last_sync_at
```python
# pseudo: web/src/pages/Settings.tsx — ConflictLog()
rows = get("/api/sync/conflicts")  # từ sync_conflicts
render_table(rows, cols=["table", "guid", "winner", "at"])  # chỉ xem
show("last_sync_at from /api/sync/status")
```
### Step 3 — Tách rõ merge vs restore hủy diệt + verify E2E
```python
# pseudo: web/src/pages/Settings.tsx — SafetyCopy()
label("restore == hủy diệt (ghi đè), sync/merge == giữ cả hai")
e2e("upload b.db on a -> counts + conflict rows visible")
```
