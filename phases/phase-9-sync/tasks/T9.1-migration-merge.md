# T9.1 — Migration v3 + merge file-carry (ATTACH, LWW + tombstone)
## Why
2 máy học offline phân kỳ DB; cần merge peer đối xứng bằng file-carry
(backup → chép tay → POST /api/sync) thay vì dựng server trung tâm, giữ restore
hủy diệt như đường riêng.
## Pre-conditions
- SQLite v2 + backup/restore hiện tại chạy được; `google/uuid` đã có indirect.
- Thiết kế oracle đã duyệt: migration v3 + merge 1 tx ATTACH incoming.
## What to do
### Step 1 — Migration v3 (guid/updated_at/deleted + backfill + trigger)
```python
# pseudo: api/migrations/v3_sync.sql — MigrateV3(db)
alter("decks/cards", add=["guid UNIQUE", "updated_at", "deleted"])  # tombstone
alter("reviews/notes", add=["guid"])  # reviews dedupe, notes union
create("sync_meta(last_sync_at), sync_conflicts(log)")
backfill("guid = uuid(), updated_at = now()")  # cho rows cũ
trigger("touch_updated_at", on=["update decks/cards"])  # chạm updated_at
```
### Step 2 — Merge 1 tx ATTACH incoming (LWW + tombstone + reviews append)
```python
# pseudo: api/sync.go — MergeIncoming(local, incoming_path)
attach(incoming_path, alias="inc")  # 1 tx duy nhất
merge("decks/cards", rule="LWW by updated_at, deleted tombstone wins")  # theo guid
append_dedupe("reviews", key="guid") then recompute("reps") and replay_srs("from latest review")
union("notes", key="guid")  # không dedupe nội dung
skip("tables IN [dict, seed]")  # bỏ qua dict/seed
warn_if("clock_skew(updated_at) > threshold")  # cảnh báo lệch đồng hồ
set("sync_meta.last_sync_at = now()")
```
### Step 3 — Smoke 2 DB phân kỳ + verify không mất dữ liệu
```python
# pseudo: scripts/smoke_sync.sh — SmokeMerge()
a, b = fork_db(seed)  # 2 bản phân kỳ: edit + delete + review mỗi bên
merged = post("/api/sync", upload=backup(b))  # chạy trên a
check("LWW wins, tombstone wins, reviews deduped, notes union, last_sync_at set")
```
